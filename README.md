# Student Performance Predictor

An AI-powered full-stack web application that predicts student academic performance using Machine Learning. The system analyzes academic and lifestyle factors to estimate student performance while providing interactive dashboards, personalized recommendations, and an integrated chatbot for academic assistance.

---

## Overview

Student Performance Predictor is designed to help educational institutions monitor and predict student academic performance using Machine Learning. The application combines a Node.js backend, Python-based ML service, and MySQL database to provide real-time predictions through an intuitive web interface.

The project integrates secure authentication, role-based access, visualization dashboards, and a chatbot to support students and administrators in making data-driven academic decisions.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/harshitharajesh19/Student-Performance-Predictor
```

### Install Node.js Dependencies

```bash
npm install
```

### Install Python Dependencies

```bash
pip install -r backend/model/requirements.txt
```

### Configure Database

- Create a MySQL database.
- Update database credentials in the backend configuration.

### Start Backend

```bash
npm run start
```

### Start Python ML Service

```bash
python backend/py_service/app.py
```

Open the application in your browser.
